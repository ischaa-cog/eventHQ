---
name: Masterclass terminology
description: The product's preferred name for the webinar/masterclass concept and legacy data compatibility
---

Treat webinar and masterclass as the same product concept. Use **Masterclass** in user-facing copy, navigation, event selectors, dashboards, and training; do not offer two separate categories to users.

**Why:** The user explicitly clarified that these are the same thing and chose Masterclass as the sole name. Existing records and integrations may still use the older webinar identifier.

**How to apply:** Keep historical webinar enum values, API paths, and records working; translate them at the display boundary and include legacy webinar resources in Masterclass views. Do not rename stored values or break routes just to update wording.
